## Único aviso retenido: alcance de una migración Prisma

`npm audit` propone Prisma **7.10.1**; no es un parche de Prisma 6. La [guía oficial de Prisma 7](https://www.prisma.io/docs/guides/upgrade-prisma-orm/v7) exige revisar ESM, generación/importaciones del cliente, adaptador PostgreSQL, pool/timeouts/TLS, configuración de URLs y carga explícita del entorno. En CRONOX también obliga a ensayar los bootstraps de pruebas, scripts de migración y controlador de publicación con esos cambios. Node 22 cumple el requisito, pero eso no resuelve el resto.

No hay evidencia de una entrada no fiable capaz de construir los objetos cíclicos en este CLI. `deepmerge-ts@8.0.2`, usado separadamente por `html-to-text`, ya está fuera del rango afectado. Se conserva 7.1.5 únicamente para respetar el contrato de Prisma 6; actualizarla mediante override a una versión mayor sin revisión sería una migración encubierta. **Este aviso no impide publicar la versión actual**, bajo el contrato existente de ejecutar el CLI solo con configuración del repositorio revisada. Reabrir la valoración si se permite configuración externa o se introduce su uso en runtime.
