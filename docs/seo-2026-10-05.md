## Rastreo e indexabilidad que se conservan

El sitemap consulta productos activos en cada petición, paginados por ID en lotes de 500. No filtra por stock. Las pruebas comprueban creación, retirada y productos agotados; no se mantiene una lista manual de slugs. Las páginas legales siguen incluidas. No se añade `lastmod`: el inventario de rutas no tiene una fuente fiable de modificación editorial y `updatedAt` genérico puede incluir cambios ajenos al contenido. El límite existente exige partición si se superan 49.000 productos, sin truncar silenciosamente.

Canónicas sin parámetros para tracking, variantes y `/tienda`; búsquedas/filtros llevan noindex cuando se solicitan al servidor. Cuenta, favoritos, cesta, checkout y recuperaciones mantienen noindex rastreable; APIs privadas excluidas por robots y protegidas por la autenticación existente. Una exclusión en robots no autentica ni garantiza desindexación. El middleware de SEO sigue después del gate público y antes de los archivos estáticos. No se toca Nginx, VPS, TLS ni PM2.

### OpenAI y otros buscadores con IA

Hay un solo grupo `User-agent: *`. Por tanto OAI-SearchBot y GPTBot heredan las mismas reglas: público y recursos permitidos; `/api/` excluido salvo las APIs públicas enumeradas para representar la tienda. No se añade un grupo específico que pierda estas exclusiones. La política de entrenamiento se conserva: no había prohibición específica de GPTBot y no se cambia esa decisión.

OAI-SearchBot se dedica a búsqueda; GPTBot, a contenido que puede utilizarse para entrenamiento; ChatGPT-User atiende recuperaciones iniciadas por usuarios y no determina la inclusión en Search. Permitir búsquedas no obliga a permitir entrenamiento. Documentación: [rastreadores de OpenAI](https://developers.openai.com/api/docs/bots).

GETs con esos tres User-Agent devolvieron 200 en robots, portada, historia y ficha. **Cambiar el User-Agent no reproduce la IP ni infraestructura del rastreador**. La herramienta web devolvió un error de acceso mientras HTTP directo y el navegador funcionaron: no basta para diagnosticar un bloqueo real. Tras publicar, el propietario puede contrastar logs de solicitudes y rangos IP oficiales; no se han inspeccionado logs privados ni cambiado protecciones. No se crea `llms.txt`, endpoints para IA, chatbot ni instrucciones para influir en respuestas. Google tampoco exige archivos o schema especiales para sus funciones de IA: [guía oficial](https://developers.google.com/search/docs/appearance/ai-features).
